# 例子 / Examples

两个 MIDI 文件都来自 [Mutopia Project](https://www.mutopiaproject.org/),
没有改动。

## turkish_march.mid

- 曲目: W. A. Mozart, Sonate KV 331, 第三乐章 Rondo alla Turca (1783)
- 来源: Mutopia Project, Mutopia-2015/08/13-108,
  <https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=108>
- 制谱/维护: Rune Zedeler, Chris Sawer (LilyPond 2.16.2)
- 许可: Public Domain (Creative Commons CC0 1.0)

文件里的速度是 60 BPM, 用的时候加 `--bpm`。

## spring.mid

- 曲目: A. Vivaldi, Le quattro stagioni, "La Primavera / Spring", Op. 8 No. 1,
  第一乐章
- 来源: Mutopia Project, Mutopia-2010/02/08-301,
  <https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=301>
- 制谱/维护: smailliw (at) gmail.com (LilyPond 2.12.3)
- 许可: Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0),
  <https://creativecommons.org/licenses/by-sa/3.0/>

这个文件不是 MIT, 仍然按 CC BY-SA 3.0 发布; 转发或修改它都要遵守这个许可。
原谱是独奏小提琴加弦乐 (solo, violinone, violintwo, viola, cello 五个音轨),
cantabile 把所有音轨都放到钢琴上弹, `solo` 音轨当旋律。

Both files come unchanged from the Mutopia Project. `turkish_march.mid` is in
the public domain (CC0). `spring.mid` is licensed CC BY-SA 3.0 and stays under
that licence; it is not covered by the MIT licence of the code.
